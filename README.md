# Rumi

Gra edukacyjna dla dzieci do nauki alfabetu i kolorów na urządzenia mobilne (Android).

## Stos technologiczny
- **React Native** + **Expo**
- **TypeScript**
- **NativeWind v4** (Tailwind CSS)

## Uruchomienie lokalne
```bash
npm install
npx expo start
```
Zeskanuj kod QR w aplikacji **Expo Go** na telefonie.
